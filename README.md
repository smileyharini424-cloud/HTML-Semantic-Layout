# HTML Semantic Layout

## Explanation

This program demonstrates the use of semantic HTML elements to create a structured webpage.

Semantic elements clearly describe the purpose of different parts of a webpage.

## Problem Statement

Create an HTML webpage using semantic elements such as header nav main section article aside and footer.

## Features

- Creates a structured webpage
- Uses semantic HTML elements
- Contains a header
- Contains navigation
- Contains main content
- Contains sections
- Contains articles
- Contains aside content
- Contains footer

## How It Works

The <header> element contains the introductory content of the webpage.

The <nav> element contains navigation links.

The <main> element contains the main content.

The <section> element groups related content.

The <article> element represents independent content.

The <aside> element contains additional information.

The <footer> element contains footer information.
